# Skyhigh Admin — Website kaise manage karein

Admin panel kholo: **https://rockyjaat47.github.io/skyhigh-travel/admin**

Login ke liye apna email daalo → **"Email me a sign-in link"** → email mein aaya link kholo. Password ki zarurat nahi.
Jo bhi aap **Save** karoge, woh website par turant live ho jaata hai.

---

## Menu mein kya hai

| Menu | Kya kar sakte ho |
| --- | --- |
| **Overview** | Nayi enquiries, pichle 7 din, kaunsi service ki demand zyada hai |
| **Enquiries** | Customer enquiries dekhna, status badalna (New → Contacted → Quoted → Closed), notes likhna, WhatsApp/email se reply, Excel (CSV) download |
| **Pages & text** | Home page, About, Mission/Vision, Values, FAQ, Privacy/Terms — har heading, paragraph aur photo |
| **Destinations** | Nayi jagah add karna, photo/description/highlights badalna, hide/show karna |
| **Packages** | Tour packages — din-wise itinerary, kya included hai, price text |
| **Services** | 6 services ka text aur photo. Jab service shuru ho jaaye, Status ko **"Available now"** kar do |
| **Photos** | Apni photos upload karo (mobile se bhi). Photos apne-aap compress ho jaati hain |
| **Contact & Google** | Phone, WhatsApp, email, address, social media links; Google search mein dikhne wala title/description |
| **Team** | Staff ko invite karna (sirf Owner) |

## Aam kaam

**Phone / WhatsApp number lagana** → Contact & Google → Contact details → number daalo
(WhatsApp: country code ke saath, jaise `919876543210`) → **Save changes**. Website par WhatsApp buttons apne-aap aa jayenge.

**Home page ki heading badalna** → Pages & text → Home page → "Main heading" → har line alag row mein → Save.

**Nayi destination add karna** → Destinations → **Add destination** → naam, country, overview likho →
"Main photo" mein **Choose photo** → upload ya list se chuno → "Live on website" ON → **Create**.

**Package ka price dikhana** → Packages → Edit → "Price text" mein likho, jaise `From ₹24,999 per person` → Save.

**Koi cheez temporarily hatana** → us card par 👁 (eye) button — hide ho jayegi, delete nahi hogi.

**Photo badalna** → kisi bhi "Choose photo / Change photo" button se. Achhi photo ke liye landscape aur kam se kam 1600px chaudi.

## Dhyan rakhein

- Customer ka passport ya card number kabhi website par na maangein.
- Privacy Policy aur Terms abhi **draft** hain — lawyer se check karwa ke hi "draft notice" band karein.
- Delete karne ke bajaye **Hide** karna safe hai — galti ho to wapas la sakte ho.
- Login link sirf usi device par kholein jahan se maanga tha.
